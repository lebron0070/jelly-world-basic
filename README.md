# 果冻世界 · 基础2.0通用版

把一个主题变成清透圆润、可以旋转观察和点击互动的Three.js微缩世界。

这份Skill将主题构思、空间布局、果冻材料、灯光、生活动画和互动反馈整理成一套制作流程，适合用AI尝试不同题材的3D小世界。

**[下载完整Skill ZIP](https://github.com/lebron0070/jelly-world-basic/raw/refs/heads/main/downloads/jelly-world-basic-public-2.0.zip)** · [阅读SKILL.md](jelly-world-basic/SKILL.md) · [使用说明](使用说明.md)

## 开始使用

1. 下载ZIP并解压，保留`jelly-world-basic`文件夹。
2. 将文件夹添加到所用工具支持的Skill目录，或直接让具备文件读取与代码执行能力的AI阅读`jelly-world-basic/SKILL.md`。
3. 给出一个主题和一个想玩的动作，让AI编写工程并实际运行检查。

例如：

```text
请先阅读 jelly-world-basic/SKILL.md。

制作一个“云朵洗衣店”果冻微缩场景：
小店架在树梢上，云朵像衣服一样被夹在晾衣绳上。
点击一朵云，它会挤出几颗软糖，再慢慢恢复形状。

使用Three.js实时3D，支持拖动观察、缩放和点击互动。
让主体清楚、材料通透、画面有轻量生活动画。
完成源码、启动命令和实际运行检查。
```

支持Skill调用的环境也可以使用`$jelly-world-basic`，并补充你的主题。先确认该环境已能读取这份Skill。

## 怎样写一个有趣的主题

可以按“主体＋意外的用途＋一个能看见结果的动作”来描述：

- 鲸鱼背着迷你书店，点击书本后，纸鱼游进透明水道。
- 小兔子在果冻月球种胡萝卜，成熟的萝卜弹出一颗小星星。
- 软糖火山开着早餐铺，吐司坐上蒸汽升降台。

这些是创意起点。制作时还需要把空间、模型和动作实现出来。

## 制作与运行

Skill提供制作说明，执行它的AI负责生成场景工程。使用环境需要能读取文件、编写代码、运行网页，并获取Three.js等依赖。

生成后按工程给出的启动命令预览，实际检查拖动、缩放、点击反馈、桌面与窄屏画面。把新的修改目标说具体，例如“让主体占画面更大一些”“点击后先压扁再回弹”“窗台增加一处生活细节”。
